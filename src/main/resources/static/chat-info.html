📱 How to Use

For Workers:

  • Click the "💬 Chat" button in the navigation
  • Type subject and message in the form at the bottom
  • Click "Send" to send message to owner
  • Hover over your messages to edit or delete them
  • Owner replies appear below your messages in green

For Owners:

  • Click the "💬" button to open chat panel
  • See all worker messages in blue bubbles
  • Click "Reply" on any message for quick response
  • Your replies appear in green bubbles
  • Hover over messages to edit or delete them
  • Badge shows count of unread messages

🔄 Automatic Features

  • Real-time updates - No page refresh needed
  • Message cleanup - When a chore is completed, related messages are automatically deleted
  • Persistent connection - WebSocket keeps you connected for instant messaging
  • Fallback polling - If WebSocket fails, system falls back to regular updates
